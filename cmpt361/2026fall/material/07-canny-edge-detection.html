Why one threshold is never enough

A single cut-off forces a bad trade. Set it high and genuine contours fragment: a boundary loses contrast where it passes into shadow, where it blurs, or where it runs nearly parallel to the light. Set it low and every noise ridge that survived suppression comes with it. The Coins image is the clean demonstration — the same rim is bright on the lit side and barely present in shadow.

Hysteresis escapes the trade by bringing in evidence that magnitude alone does not carry: spatial continuity. Noise responses are isolated speckles. Real edges form connected chains. A middling pixel is credible if it continues a contour that already proved itself somewhere.

What the animation is doing

Stage 05 opens with classification and nothing else: orange above T_high, green between the two thresholds, dropped below T_low. Extraction then proceeds one connected component at a time. Each begins at the strongest pixel not yet visited — the high threshold acting as an admission test — and walks the 8-neighbourhood depth-first, admitting any neighbour above the low threshold. The component under construction is pink; finished ones turn red.

The traversal order is presentation only. Breadth-first, depth-first or a raster sweep repeated to convergence all produce the identical edge map, because the rule is reachability in the graph of pixels above T_low from any pixel above T_high. Visiting in descending seed magnitude just makes the story legible: start where the evidence is strongest, then follow it out.

Pipeline computed live in the browser: separable Gaussian, 3×3 Sobel, gradient orientation quantised to four sectors for suppression, 8-connected hysteresis. Magnitudes are normalised by the maximum surviving response, so thresholds read 0–1 on every image. Sample images from the scikit-image data set.
