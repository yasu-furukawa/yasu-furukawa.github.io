Segmentation by clustering

Interactive companion to the CMPT 361 lecture on segmentation: k-means, its use on image pixels, textons, mean shift, and SLIC superpixels.

Alternate two easy problems

If we knew the means, assigning points would be trivial. If we knew the assignments, the means would be trivial. So start from random centers and alternate. Each move can only lower the objective Σi ‖xi − μyi‖².

Objective after each step. Circles: assign (fix μ, choose y). Squares: move (fix y, choose μ).

Every pixel is a point

Describe each pixel by its color (r, g, b) and run k-means. Nothing tells k-means that pixels far apart in the image probably belong to different objects. Adding position (r, g, b, x, y) is one fix, and the position weight sets how much it counts.

On the vegetables at weight 0, both cucumber slices land in the same cluster even though they are far apart. Around weight 0.5 they separate, but clusters also start swallowing nearby pixels of other colors. Push the weight further and the clusters become patches of image area that ignore color.

Runs start from spread-out centers (k-means++) so that changing one setting gives a fair comparison.

Cluster what the neighborhood looks like

The regions in these images have the same average brightness, so clustering brightness cannot tell them apart. Textons describe local structure instead.

Filter the image with the bank, so each pixel gets a 10-number response vector. K-means on those vectors gives the textons. Each pixel is then described by the histogram of texton labels in a window around it, and k-means on the histograms gives the texture regions.

Tap any image to move the window and see its histogram.

A small window gives noisy histograms. A large one blurs across region boundaries. The photo textures are harder than the drawn ones, so expect ragged boundaries between gravel and grass.

Climb to the nearest peak

Mean shift looks for modes, the peaks of point density. Put a window down, find the center of mass of the points inside, move the window there, and repeat. Points whose windows climb to the same peak form one cluster.

Search window. Tap the plot to place it. Center of mass of the points inside Mean shift vector

There is no k. The window radius decides how many peaks survive: small windows find many little peaks, large ones merge them. Shading shows how many points a window centered there would contain.

Tap a pixel to see which centers compete for it. Each center only looks at pixels inside its own 2S×2S square.

K-means, but local

SLIC is k-means on (l, a, b, x, y) with two changes: centers start on a regular grid, and each center only searches the 2S×2S square around it. Assignment costs about the same for any number of superpixels.

  1. Place centers on a grid with step S
  2. Move each center to the lowest-gradient pixel in its 3×3 neighborhood
  3. Repeat
  4. For each center
  5. Assign the best-matching pixels in its 2S×2S square, using distance D
  6. End for
  7. Recompute centers; measure how far they moved, E
  8. Until E ≤ threshold
  9. Enforce connectivity

D = √( dlab² + (dxy / S)² m² ), so m trades color similarity against compactness.

Low m: boundaries hug color edges, but shapes get irregular. High m: compact, grid-like cells that cut through edges.
