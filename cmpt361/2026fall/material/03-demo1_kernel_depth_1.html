When the image gets channels, the kernel gets depth

You know this picture for a grey image: a 3×3 kernel slides over a 2D grid and every stop produces one number. A colour image is three grids stacked. The kernel simply grows a matching third dimension — 3×3×3, one slab per channel — and each stop is now a sum of 27 products. The output is still one number per position: one kernel always makes one channel.
