Visual computing: what they share
Linear algebra
Matrices, vectors, and transforms are the common language of both fields.
Image representations
Pixels, color spaces, filters — the raw material of both rendering and perception.
3D geometry
Camera models, depth, and spatial structure appear in CV and CG alike.
Machine learning
Modern CV and CG both rely heavily on neural networks — increasingly, the boundary blurs.

A note on academic integrity

Code must be your own original work — written by you, understood by you.

  • No LLMs for code generation Using GitHub Copilot, ChatGPT, Claude, etc. to write assignment code is not permitted.
  • Close paraphrasing counts as copying "Following" existing code line-by-line is not okay, even without copy-paste.
  • Discuss concepts freely — submit your own implementation Talking through ideas with classmates is encouraged. Sharing code is not.
Why? The math and coding skills this course builds are foundational. Shortcuts now mean gaps later — in interviews, in research, and in your work.
